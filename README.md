# Бескрайняя Плоть 002 — «Пожиратель»

Маленькая HTML5-игра для Яндекс Игр.

## Запуск локально (без SDK)

cd 002
python3 -m http.server 8000
# http://localhost:8000

## Запуск локально (с SDK)

npm install -g @yandex-games/sdk-dev-proxy
sdk-dev-proxy -p .
# открыть порт из вывода

## Управление

- ПК: зажми ЛКМ и веди мышь.
- Мобильный: веди палец по экрану.
- Кнопки в меню: мышь / тап.

## Механика

- Ты — существо. Растёшь, поглощая меньших.
- Большие тебя убивают.
- Победа: размер 160.
- Проигрыш: столкновение с большим.
